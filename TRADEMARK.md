## Project name

Use **Truss** when referring to the project and `truss` for the repository name.
When distributing a fork, we encourage you to identify it as a fork and not
imply endorsement by the upstream project. This guidance adds no conditions
to the software license.

## Attribution

Preserve existing copyright and license notices when redistributing the software.
Follow Apache-2.0 §4 for modification notices and attribution. See [NOTICE](NOTICE)
for project and third-party attribution.
